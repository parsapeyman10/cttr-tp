# CTTR HD Launcher (اندروید)

یک اپلیکیشن اندروید (Kotlin) که از بستهٔ تکسچر **Crash Tag Team Racing HD** این
مخزن استفاده می‌کند و شامل یک **گیم‌پد لمسی (on-screen mobile gamepad)** کامل است.

## قابلیت‌ها
- **نصب‌کننده تکسچر HD** با استفاده از Storage Access Framework (بدون دسترسی خطرناک).
  تکسچرها را از پوشهٔ استخراج‌شده به داخل پوشهٔ `textures/<SERIAL>/replacements`
  ایمولاتور (NetherSX2 / AetherSX2) کپی می‌کند.
- **اجرای بازی**: تشخیص خودکار ایمولاتور نصب‌شده و اجرای فایل ISO بازی.
- **گیم‌پد موبایل**: استیک آنالوگ چندلمسی + دکمه‌های مثلث/ضربدر/مربع/دایره + L1/R1/L2/R2
  + Start/Select. پشتیبانی از شفافیت و حالت دست‌چپ/راست و لرزش (haptic).
- **دمو**: صفحه‌ای که از تکسچرهای بازی استفاده می‌کند و با گیم‌پد لمسی کنترل می‌شود
  (ماشین با استیک حرکت می‌کند، X شتاب، □ ترمز).

## نحوهٔ بیلد

### الف) Android Studio (ساده‌ترین راه)
1. Android Studio را باز کن و **Open** را روی پوشهٔ `android-app` بزن.
2. صبر کن همگام‌سازی Gradle انجام شود (گریدل ۸.۲ را خودش دانلود می‌کند).
3. دستگاه/شبیه‌ساز را وصل کن و **Run** (یا `Build > Build Bundle(s)/APK > Build APK`).

### ب) خط فرمان (CLI)
Gradle 8.2 را نصب کن، سپس:
```bash
cd android-app
gradle assembleDebug --no-daemon
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

### ج) GitHub Actions (بدون نیاز به کامپیوتر خودت)
روی تب **Actions** در گیت‌هاب کلیک کن، ورک‌فلو **Build Android APK** را اجرا کن
(`workflow_dispatch`) یا هر بار پوش بزن. در انتهای اجرا، آرتیفکت
`cttr-hd-launcher-apk` شامل فایل APK قابل نصب دانلود داده می‌شود.

## نحوهٔ استفاده در گوشی
1. **نصب تکسچرها**: دکمه «نصب تکسچرهای HD» → ابتدا پوشهٔ بستهٔ تکسچر (خروجی unzip شدهٔ
   این مخزن) را انتخاب کن → سپس پوشهٔ مقصد را داخل حافظهٔ ایمولاتور انتخاب کن:
   `Android/data/<بسته ایمولاتور>/files/textures/<سریال>/replacements`
   - سریال‌ها: `SLUS-21191` (NTSC-U)، `SLES-53439` (PAL)، `SLPM-66090` (NTSC-J)
2. **اجرای بازی**: دکمه «اجرای بازی» → فایل ISO را انتخاب کن. (ایمولاتور باید نصب باشد.)
3. **تست گیم‌پد**: دکمه «تست گیم‌پد (دمو)» را بزن و استیک/دکمه‌ها را امتحان کن.
4. **تنظیمات**: شفافیت گیم‌پد و حالت دست‌چپ/راست را تغییر بده.

## ساختار
```
android-app/
  app/src/main/assets/cttr/   # تکسچرهای منتخب باندل‌شده (برندینگ + دمو)
  app/src/main/java/com/cttr/hdlauncher/
      GamepadView.kt          # گیم‌پد لمسی (کنترل‌کنندهٔ اصلی)
      GamepadState.kt         # مدل وضعیت گیم‌پد
      PlayfieldView.kt        # صفحهٔ دمو با تکسچرهای بازی
      GamepadDemoActivity.kt  # فعالیت دمو
      MainActivity.kt         # منوی اصلی + نصب/اجرا/تنظیمات
      TextureInstaller.kt     # کپی تکسچر با SAF
      EmulatorLauncher.kt     # تشخیص و اجرای ایمولاتور
  .github/workflows/build-apk.yml   # بیلد خودکار APK
```

> نکته: بستهٔ کامل تکسچر ۲۰۸ مگابایت است؛ بنابراین داخل APK باندل نشده و در زمان
> اجرا از حافظهٔ گوشی (از طریق SAF) خوانده/کپی می‌شود. تعداد کمی تکسچر سبک برای
> رابط کاربری و دمو در `assets/cttr/` گنجانده شده‌اند.
